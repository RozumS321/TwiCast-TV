# TwiCast TV — дизайн (handoff)

Источник: холст «TwiCast TV — дизайн» в Claude (Design): https://claude.ai/artifact/XFCKut6eRqyEoyRBbRwDLX. Экраны 1280×720 смотреть там.
Темы: **светлая** и **тёмная** (холст: ряд «Тёмная тема»). Выбор — «Настройки · Оформление»: Как в системе / Светлая / Тёмная.

Целевой стек: Kotlin, Compose for TV (`androidx.tv:tv-material`), MVVM + UDF, Hilt, Retrofit + kotlinx.serialization, Coil 3.
Размеры в макетах указаны в px при ширине 1280 — для ТВ (960dp логической ширины на 1080p) **переводить 1:1 в dp и проверить на устройстве**; если тесно — масштаб 0.75.

## Языки

Русский (`values-ru`), украинский (`values-uk`), английский (`values`, он же запасной для любого другого языка ТВ). Выбор — «Настройки · Язык»; до выбора берётся язык телевизора. Каждый язык в настройках подписан на самом себе. Клавиатура поиска: раскладки LAT / РУС / УКР, по умолчанию — язык интерфейса; кнопка раскладки открывает выбор вместо нижнего ряда. «Популярное в регионе» по-прежнему по языку телевизора, а не интерфейса.

## Размеры и радиусы

- Отступ контента от свёрнутого сайдбара: 40; верх экрана: 30; шаг между секциями: 22–26.
- Радиусы: карточка 16, превью 14, обложка 12–14, кнопка 16, чип 20 (pill), бейдж 6–8, панели (Login/Profile) 28.
- Карточка стрима: превью 16:9 (240×135 на главной, 212×119 в плотных рядах), под ним аватар 32 + заголовок + «канал · категория».
- Кнопки: основная 52 высоты, padding 26, primary + тень `0 10 24 primary@32%`; вторичная — surface + рамка outline. Чипы 40 высоты.

## Фокус и анимации (из ТЗ)

| Что | Параметры |
|---|---|
| Фокус карточки | scale 1.0 → **1.06** (в ТЗ 1.08 — на 1.08 соседи перекрываются), 200ms, Decelerate; рамка 3dp primary + тень 18dp primary@28%; фон карточки → surface |
| Выход из фокуса | scale → 1.0, 200ms |
| Сайдбар | 88 ↔ 264dp, **overlay поверх контента** (не менять ширину контента → без relayout), 250ms FastOutSlowIn; подписи alpha 0→1 за 150ms с задержкой 80ms; скрим на контент |
| Пункт сайдбара в фокусе | заливка primary, иконка/текст белые, тень primary; активный раздел без фокуса — primaryContainer + полоска 4dp слева |
| Компоновка фокуса | у рядов `clipChildren=false`/достаточный padding, чтобы 1.06 не обрезался |
